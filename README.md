# ВПО для адаптера USB-CAN LC_CANNABLE_V2.1

Данный репозиторий является форком проекта 

```
https://github.com/tymmothy/candleLight_fw_canable_v2_fd
```

Оригинальную справку можно прочитать в файле ```README.EN.md```

## Назначение

Данная прошивка позволяется сделать адаптер ```LC_CANNABLE_V2.1``` совместимым с 
ПО ```dronecan_gui_tool```

## Прошивка

1. Скачайте утилиту для прошивки устройства в режиме DFU.

Откройте терминал и выполните команду:

```
sudo apt install dfu-util
```

Дождитесь окончания установки программы.

2. Переведите адаптер в режим DFU. 

Отключите устройство от USB. Замкните перемычкой контакты ```BOOT0```.
Подключите устройство обратно к USB.

3. Проверьте, в каком режиме находится подключённое устройство.

Откройте терминал в диреткории с прошивкой и выполните команду:

```
lsusb | grep 0483:df11
```

В случае успеха вы должны увидеть строку, содержащую строку: 

```
STMicroelectronics STM Device in DFU Mode.
```

4. Перепрошейте устройство.

Выполните в терминале команду:

```
sudo dfu-util -d 0483:df11 -a 0 -s 0x08000000:leave -D canable2_fw.bin
```

Дождитесь окончания записи прошивки. После окончания процедуры можно сразу проверить
наличие устройства в системе с помощью команды ```ip link show```. В случае успеха
вы увидете строку, аналогичную этой:

```
12: can1: <NOARP,ECHO> mtu 16 qdisc noop state DOWN mode DEFAULT group default qlen 10
    link/can 
```

Снимите перемычку с разъёма ```BOOT0```.

## Использование

Теперь когда адаптер начал определяться в системе, его можно использовать с ПО ```dronecan_gui_tool```,
но для начала нужно выполнить несколько команд:

```
sudo ip link set can0 type can bitrate 1000000
```

```
sudo ip link set up can0
```

Теперь можно запускать ```dronecan_gui_tool```.
